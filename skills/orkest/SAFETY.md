Tool-independent invariants apply in every harness. Claude and Codex use their
verified native hook/adapter contracts. Grok's native SessionStart requires a
trusted project; otherwise report the init/trust prerequisite without modifying
global trust. Other protections run inline where native hooks are unavailable.
Never claim startup/native discovery acceptance from unit configuration tests.
Keep user disables, explicit event arrays and customized/local handlers.

Startup and doctor cannot run feature actions or promote. The upgrade release
journal and document layout marker prove different stages. Missing consumer
deployment/readiness or a dirty tree defers migration; edited old skills remain
recoverable and are never deleted because their name matches a retired name.
