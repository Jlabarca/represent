如何使用這份圖表

        
所有操作都在你的瀏覽器中執行，不會傳送任何資料。

        

          
滑過節點
標示該節點及其整條連接鏈，其餘節點淡化。

          
雙擊節點
釘選鏈結標示使其保持顯示；再次雙擊可取消釘選。

          
單擊節點
開啟詳細資訊面板；點擊其他節點會清除已釘選的標示。

          
拖曳節點
移動節點位置，連接線會跟著移動。

          
拖曳畫布
平移整張圖。

          
滾動 / 縮放
Zoom in或Zoom out；按「⊡ Fit」可顯示全圖。

          
分頁
在上方工具列切換不同檢視。

          
◐ / ◑
切換Light / Dark主題。

          
⚑ Audit overlaps
檢查節點是否重疊；發現時可一鍵自動修正版面。

          
▶ Walkthrough
只在這個分頁有作者撰寫的Walkthrough步驟時才會出現；播放時淡化其餘節點並聚焦目前步驟，← / → 切換步驟；關閉鈕會直接結束Walkthrough並還原畫面，Esc 則只關閉目前最上層開啟的畫面（Help → 面板 → Walkthrough）。

          
Edge colour / Edge labels
選擇簡報用的高對比連接線與標籤顏色；「↺ Colours」恢復主題預設。

          
↓ SVG / PNG
將目前檢視匯出為自包含圖片；PNG 可選原圖、16:9 或 4:3，固定比例不會拉伸內容。
